Who does each step, and with what

Blue = you (a person), green = a tool (deterministic code or library), clay = the model (an NVIDIA NIM call).

#StepYouToolModelWhat we actually used
Ingestion (offline)
1Collect documentsFiles in a folder → scripts/ingest.py, or upload → POST /api/ingest (admin token)
2Read text / OCRpypdf for the text layer; if a page has under 20 characters, pypdfium2 renders it and Tesseract 5 reads it
3Clean and chunkRegex cleanup; sentence packing, 1,200 characters per chunk, 200 overlap (crag/ingest.py)
4Extract entities and relationsnvidia/nemotron-3.5-lightning-30b-a3b, temperature 0, thinking off, JSON schema in the prompt, 4 parallel calls
5Resolve entitiesLower-case, punctuation-free name keys; placeholder stoplist; relations kept only if both ends exist
6Embed chunks and entitiesnvidia/nemotron-3.5-embed-1b, 2,048 dimensions, L2-normalised, input_type passage / query
7Store graph and vectorsNeo4j 5.26 with cosine HNSW indexes, or NetworkX + NumPy snapshot (graph.json, vectors.npz)
Query (online, LangGraph)
8Ask a questionWeb UI (HTML/CSS/JS) or POST /api/ask; FastAPI validates and rate-limits (20/min/IP)
9Analyze intentNemotron returns {"intent": qa|experts|recommend, "entities": [...]}
10Vector retrievalModel embeds the query; tool ranks passages by cosine (NumPy matmul, or Neo4j db.index.vector.queryNodes)
11Entity linking + graph expansionExact name keys + nearest entity vectors (cosine ≥ 0.35); 2-hop BFS (NetworkX) or Cypher shortestPath
12Fuse rankingsReciprocal Rank Fusion (k = 60); top 3 semantic passages always kept; 6 passages + up to 25 graph facts
13Grade evidence (corrective loop)Nemotron judges sufficiency; LangGraph conditional edge loops back once with a rewritten query
14Rank experts / documentsExperts: 0.4 graph evidence (relations to the question's entities) + 0.3 coverage + 0.3 semantic. Documents: 0.7 cosine + 0.3 Jaccard
15Generate cited answerNemotron, grounded prompt; each passage labelled with its document and subject; must cite [S#] and [F#]
16Explain and visualiseRegex pulls cited markers → reasoning path; Cytoscape.js draws it in clay
Operations
17EvaluateYou run scripts/evaluate.py; tool computes P@5, hit rate, exact match; model acts as judge for answer quality
18DeployDocker Compose (Neo4j + API) for production; Vercel serverless for the public read-only demo; GitHub for code
