          How an answer is made

          1. Understand

            The language model classifies the question as a lookup, an expert search or a recommendation, and names its key entities.

          2. Retrieve

            Passages are found by meaning with embeddings, and entities are linked to the graph.

          3. Expand

            The graph is walked two relations deep to collect facts that plain text search misses.

          4. Check

            The model grades the evidence; if it is thin, the query is rewritten and retrieval runs again.

          5. Answer

            The answer cites each passage [S] and graph fact [F] it relies on, and the cited path is shown.
